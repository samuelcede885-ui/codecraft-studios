# Instalación en Claude Code

1. Descomprimir `skill.zip`.
2. Copiar la carpeta `cinematic-hero-banners` en `~/.claude/skills/` (global) o `.claude/skills/` dentro del proyecto (local).
3. Reiniciar la sesión de Claude Code si no detecta la nueva Skill.
4. Pedir: `Usa la skill cinematic-hero-banners. Crea el hero de [marca/producto] inspirado en las referencias adjuntas: tipografía XXL, escena por capas, animación de entrada, floating, parallax y CTA. Hazlo responsive y verifica build.`

Las imágenes de `assets/inspiration` son muestras para estudiar estilo; no son imágenes licenciadas para uso en producción. Puedes aportar assets propios del proyecto.
