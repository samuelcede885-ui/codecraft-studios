# CodeCraft Studio

Web del estudio CodeCraft Studio (diseño y desarrollo de webs y apps).

- `index.html` — página principal
- `identidad.html` — guía de identidad de marca (logo, colores, tipografía, voz)

Es HTML/CSS/JS estático, sin dependencias. Para verla en local:

```sh
python3 -m http.server 8000
# abrir http://localhost:8000
```

## Paleta

| Nombre | Hex | Uso |
| --- | --- | --- |
| Océano | `#19587B` | Principal |
| Crema | `#F6EEDE` | Logo, textos sobre azul |
| Cielo | `#85B2CF` | Acentos |
| Tinta | `#061C4B` | Botones, sombras |

Tipografías: Bebas Neue, Pinyon Script, Inter Tight (Google Fonts).
